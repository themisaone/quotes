Installation guide
==================

Recommended single-user install: SQLite
---------------------------------------

For a simple local installation, use the SQLite package flow:

   INSTALL-SQLITE.txt

That installer creates local runtime files, a local SQLite database, and a
standard quote/note vault profile from:

   inst/sqlite-standard/

Git is not required for end users when you distribute a package created with:

   npm run package-sqlite

Developer / server install: Postgres
------------------------------------

Postgres remains useful for a server install or development environment where a
real database service is preferred.

1) Install dependencies

   npm install

2) Install and start Postgres

   sudo apt update
   sudo apt install postgresql postgresql-contrib -y
   sudo systemctl start postgresql
   sudo systemctl enable postgresql

3) Create database and user

   sudo -u postgres psql

   CREATE USER notes_user WITH PASSWORD 'change_me_please';
   CREATE DATABASE notes_db OWNER notes_user;
   \q

4) Create .env

   cp .env.example .env

   Then set:

   DB_BACKEND=postgres
   DB_HOST=localhost
   DB_PORT=5432
   DB_NAME=notes_db
   DB_USER=notes_user
   DB_PASSWORD=<your password>
   PORT=4000

5) Configure config/local.json

   Use a vault path for attachments, settings, and palettes:

   {
     "vaultPath": "/home/you/Documents/NoteArchiveVault",
     "activeMode": "ALL"
   }

6) Run migrations and start

   npm run migrate
   npm start

Open:

   http://localhost:4000
